# Hello, I'm Samuel

**Developer focused on AppSec & AI Agent security**

I build open source security tools — from vulnerability triage to adversarial testing for LLM agents. I design and run benchmarks against prompt injection, data leakage, MCP server exploits, and cost-based attacks. I also ship production apps with Flutter and Python. Currently building [depquiet](https://github.com/samuelrojas-dev/depquiet), an SCA triage tool that cuts through vulnerability alert noise.

## Projects

- **[depquiet](https://github.com/samuelrojas-dev/depquiet)** · [![PyPI](https://img.shields.io/pypi/v/depquiet)](https://pypi.org/project/depquiet/) · [![codecov](https://img.shields.io/badge/coverage-100%25-brightgreen)](https://github.com/samuelrojas-dev/depquiet): an SCA triage tool that cuts through vulnerability alert noise. 6 parsers (npm, pip, trivy, grype, dependabot, snyk), EPSS scoring, AST-based reachability analysis, 21 community templates, SARIF output, GitHub Action — 292 tests, 100% coverage, published on PyPI.
- **[rogue-llm](https://github.com/samuelrojas-dev/rogue-llm)** · [![PyPI](https://img.shields.io/pypi/v/rogue-llm)](https://pypi.org/project/rogue-llm/): an adversarial testing toolkit for LLM agents. Ships a hostile model server, 7 attack profiles, a security scanner, MCP server auditing, a framework benchmark with badge generation, and a pytest plugin — all offline, no API keys needed. 114 tests, published on PyPI.
- **[dowbench](https://github.com/samuelrojas-dev/agent-cost-bench)**: a reproducible benchmark of denial-of-wallet attacks against tool-using LLM agents. Found a real 8.8× cost-amplification attack against Gemini and the one defense (out of five tested) that stops it — every result is replay-verified and reproducible from a published cassette, no API key needed.
- **[agent-security-lab](https://github.com/samuelrojas-dev/agent-security-lab)**: a B2B sales agent built on Gemini and Supabase, evaluated against prompt-injection and information-disclosure attacks, with 34 adversarial test cases and an automated evaluator.
- **Checho**: an offline-first financial education app built with Flutter, with a CI pipeline on GitHub Actions.
